- 所有对外部资源的访问（DashScope API Key、临时 wav 文件、日志 boot.log）都通过路径拼接而非硬编码绝对路径，保证跨机器可移植。
- GUI 组件统一封装为类（LogWindow、AIChatWindow 等），并提供 `show()` 方法实现「已存在则 deiconify/lift，不存在则新建」的单例式窗口管理。
- 异步/耗时任务（OCR、翻译、TTS、音频录制）均放在独立线程中执行，通过 queue 与主线程通信，避免阻塞 Tkinter 事件循环。
- 外部依赖失败时采用多策略回退：音频录制优先 soundcard，失败则 pyaudiowpatch，再失败则 pyaudio；虚拟环境重建前会先尝试增量 pip --upgrade。
