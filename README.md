# 屏幕翻译工具 (Screen Translator)

基于 Python + Tkinter 开发的屏幕翻译工具，支持截图识别、AI翻译和语音合成功能。

## 功能特性

- 🖼️ **截图识别**：选择屏幕区域进行文字识别
- 🌐 **AI翻译**：使用通义千问API进行智能翻译
- 🔊 **语音合成**：支持将原文合成语音播放
- ⚡ **变速播放**：支持正常速度和0.75倍速切换
- 💫 **实时预览**：翻译结果实时显示在浮动窗口
- 🎯 **快捷键支持**：支持快捷键重新识别

## 必备环境

### 系统要求
- Windows 10/11 (推荐)
- Python 3.8+

### 依赖库安装

```bash
pip install -r requirements.txt
```

### 依赖列表
- `tkinter` - 图形界面框架
- `pyautogui` - 屏幕截图
- `Pillow` - 图像处理
- `openai` - OpenAI API客户端（用于通义千问）
- `dashscope` - 阿里云DashScope SDK（用于语音合成）
- `pyaudio` - 音频播放
- `wave` - WAV文件处理

### API Key 配置

1. **通义千问 API Key**（翻译功能）
   - 注册阿里云账号并开通通义千问服务
   - 设置环境变量：`DASHSCOPE_API_KEY=your_api_key`
   - 或在代码中直接配置 `api_key` 变量
   - 在程序所在目录创建key.txt，并填入API Key

2. **CosyVoice API Key**（语音合成功能）
   - 注册阿里云账号并开通DashScope服务
   - 使用与通义千问相同的API Key
   - 在程序所在目录创建key.txt，并填入API Key

## 使用方法

### 启动程序

```bash
python screen_translator_with_qwen.py
```

### 基本操作

1. **选择识别区域**
   - 点击「选择识别区域」按钮
   - 拖动鼠标选择要识别的屏幕区域
   - 松开鼠标后自动进行OCR识别和翻译

2. **查看翻译结果**
   - 翻译结果会显示在浮动窗口中
   - 窗口显示翻译文本和原文

3. **语音播放**
   - 点击翻译窗口旁的「发音」按钮
   - 第一次点击以正常速度播放
   - 再次点击切换到0.75倍速
   - 循环切换速度

4. **重新识别**
   - 使用快捷键重新识别当前区域（默认为F1）
   - 或点击主界面的「选择识别区域」按钮重新选择

5. **关闭窗口**
   - 点击主界面的「关闭」按钮关闭所有窗口
   - 或直接关闭主窗口

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| F1 | 重新识别当前区域 |

## 核心功能实现

### 1. 截图识别
使用 `pyautogui.screenshot()` 进行屏幕截图，配合OCR技术识别文字。

### 2. AI翻译
调用通义千问API进行智能翻译，支持多语言互译。

### 3. 语音合成
使用阿里云CosyVoice语音合成API，支持多种音色和采样率。

### 4. 变速播放
通过音频重采样算法实现0.75倍速播放功能。

## 注意事项

1. 首次使用需要配置API Key
2. 网络环境需要能够访问阿里云API
3. 语音合成功能会生成临时文件 `cosyvoice.wav`，程序关闭时自动清理
4. 建议在安静环境下使用语音播放功能
